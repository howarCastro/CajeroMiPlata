# Épica 1: Autenticación y Gestión de Cuentas
## Feature 1.1: Registro e Identificación
US-001: Como usuario nuevo, quiero registrarme con mis datos personales para crear mi cuenta y acceder a los servicios del cajero.

## Feature 1.2: Acceso y Seguridad
US-002: Como usuario registrado, quiero iniciar sesión con mis credenciales para acceder al menú de transacciones.
US-003: Como usuario, quiero un límite de 3 intentos de acceso para proteger mi cuenta de usos indebidos.

# Épica 2: Gestión de Transacciones
## Feature 2.1: Consultas de Saldo e Historial
US-004: Como usuario con sesión iniciada, quiero consultar mi saldo actual para conocer mi dinero disponible.
US-007: Como usuario con sesión iniciada, quiero ver mi historial de movimientos para revisar el detalle de todas mis operaciones.

## Feature 2.2: Operaciones de Dinero
US-005: Como usuario con sesión iniciada, quiero retirar dinero de mi cuenta para disponer de efectivo.
US-006: Como usuario con sesión iniciada, quiero consignar dinero a mi cuenta para incrementar mi saldo.

# Épica 3: Sesión y Persistencia
## Feature 3.1: Control de Sesión
US-008: Como usuario, quiero cerrar mi sesión al terminar para garantizar la seguridad de mi cuenta.

## Feature 3.2: Almacenamiento Permanente
US-009: Como usuario, quiero que mis datos se guarden automáticamente para conservar mi información entre sesiones.
